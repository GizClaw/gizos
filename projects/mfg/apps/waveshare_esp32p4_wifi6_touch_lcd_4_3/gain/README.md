# P4 单机扬声器／麦克风增益扫描

构建 `//projects/mfg/apps/waveshare_esp32p4_wifi6_touch_lcd_4_3:gain_package`
（`--config=esp32p4`），使用 H2Loader 临时替换 Loader 镜像。
先备份原包和校验值，保留 MFG 记录；结束后恢复原 Loader 包并核对两份分区。
校准期间 MFG gate 保持有效，已有验收记录保留。
安装完成且 Stage 清空后再重启 Loader 开始扫描；安装过程不占用音频。

扬声器扫描 93、97、100%，ES8311 上限为 0xbf；麦克风扫描
63、79、95、100%，对应 ES7210 请求约 24、30、36、38 dB
（最高物理档 37.5 dB）。AEC 始终开启，双麦 lane 1/3、reference
lane 0、reference 数字倍数 16 不变。

每组执行静音、原强度测试音、五倍测试音、静音，共 48 个窗口。
信号为已有单机探针的 500/1000/2500 Hz，数字峰值 4478 和 22390；
每窗口实际计分 96 帧，16 kHz、512 samples，先预热再计分。
保持环境安静、设备位置不变。日志只存功率、峰值和削波统计。

`analyze.py --log <log> --uid <uid> --version <version>` 验证完整实际
ADC/AEC/DAC 窗口、身份、时序、控制回读、背景稳定性、reference 活性、
30000 peak 余量和至少 10 dB 的总回声功率抑制。失败组合保留原因。
扫描不会写入最终增益或 MFG 通过记录；完成记录包含控制恢复结果。

这些数据用于选择单机远端探针条件下的候选。最终增益仍须回到 MFG
做近端讲话、双讲和回放人工确认。数字余量不证明模拟功放无失真，
也不证明连续增益范围的全局最大值。
