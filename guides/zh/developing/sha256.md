# SHA-256

`//libs/sha256` 提供不分配内存、只使用调用方 context 的增量 SHA-256 和十六进制输出，供流式下载、Lua App 安装及 H2Loader 共用。Public Header 是 [API Reference](/references/sha256) 的 source of truth；每个并发摘要使用独立 context，完成后 context 清零，继续计算前重新初始化。

H2Loader 保留既有函数名、struct tag 和布局，通过无 strict-aliasing 转型的薄适配调用共享实现。WL82 的原生 App client 和 Loader 也从各自已有的 firmware library component 导入共享 archive 与 public header，不维护原生算法副本。库自己的测试覆盖标准向量、所有切分点、55/63/64/65 字节边界、百万字节输入和交错 context；H2Loader 的兼容入口仍单独测试。
