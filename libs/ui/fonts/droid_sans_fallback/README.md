# Droid Sans Fallback font resource

`DroidSansFallback.ttf` is the unmodified Droid Sans Fallback Regular, version 2.55b, from [AOSP Android 4.4](https://android.googlesource.com/platform/frameworks/base/+/1aed5ea2dcf7cb0bf35635f378b2326461ba0df0/data/fonts/DroidSansFallback.ttf). It retains the original outlines, hinting and 34,492 Unicode mappings. Consumers reference `//libs/ui/fonts/droid_sans_fallback:DroidSansFallback.ttf` and generate subsets with their own text, sizes and conversion policy.

The source is 3,939,852 bytes, with SHA-256 `05d71b179ef97b82cf1bb91cef290c600a510f77f39b4964359e3ef88378c79d` and Git blob `2b75113962a47a66274144a4fa0d6ae52b5d7db7`. These are the same bytes previously owned by Fruit Slice and recorded by [H106's source policy](https://github.com/h2vivi/firmwares/blob/9762e1cba0fa4f850431ce9cfa4c408305aebc27/projects/h106/assets/raw/h106/common/fonts/runtime-font.source.json).
